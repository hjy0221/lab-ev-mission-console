# LAB EV Mission Console 발표 데모

약 90초 안에 다섯 단계의 흐름을 보여주는 것을 기준으로 합니다.

## 1. Mission

“LAB EV는 차량이 아니라 현장 연구의 작업 흐름을 설계합니다. 차량, 위치, 측정 장비가 준비되면 하나의 Mission을 시작합니다.”

`START MISSION`을 누릅니다.

## 2. Drive

“이동 중에는 운전자에게 필요한 도착 시간과 거리만 크게 보여줍니다. 세부 연구 기능은 주차 전까지 노출하지 않습니다.”

`ARRIVE AT SITE`를 누릅니다.

## 3. Field Measurement

“차량이 주차되면 Field Mode가 열리고 PM2.5, 온도, 습도 센서가 하나의 측정 세션으로 기록됩니다.”

`START MEASUREMENT`를 누르고 그래프가 움직이는 모습을 보여준 뒤 `STOP & ANALYZE`를 누릅니다.

## 4. Analysis

“세 지점의 값을 비교하고, AI는 관찰된 차이만 설명합니다. 현장 메모와 측정값의 동시 발생을 인과관계로 단정하지 않습니다.”

`RUN ANALYSIS`를 누른 뒤 결과를 확인하고 `CREATE REPORT`를 누릅니다.

## 5. Report

“측정 결과와 현장 메모, 후속 측정 권고가 보고서 초안으로 연결됩니다. 연구원은 차량에서 내리기 전에 현장 업무를 마칠 수 있습니다.”

필요하면 `NEW MISSION`으로 처음부터 다시 시작합니다.
